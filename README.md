## 📌 About the Project (Proje Hakkında)

**Baş Grup İnşaat Web Platform** is an enterprise-grade, responsive single-page web application developed to showcase the 36-year legacy, prestigious residential developments, urban transformation projects, and commercial plazas of Baş Grup İnşaat. Designed with a luxury aesthetic and engineering precision, the platform bridges modern digital architecture with the company's physical construction excellence.

*(**Baş Grup İnşaat Web Platformu**, Baş Grup İnşaat'ın 36 yılı aşkın köklü sektör tecrübesini, lüks konut projelerini, kentsel dönüşüm çalışmalarını ve ticari plazalarını dijital dünyada en prestijli şekilde yansıtmak amacıyla geliştirilmiş kurumsal bir web platformudur. Lüks tasarım dili ve yüksek mühendislik disiplinini harmanlayarak, şirketin fiziksel inşaat kalitesini modern bir dijital vitrinle buluşturur.)*

The primary objective of the platform is to deliver a seamless, ultra-fast, and trustworthy experience for prospective property buyers, investors, and urban transformation stakeholders. Featuring an interactive multi-photo project showcase, smooth scroll-triggered statistics, dynamic lightbox galleries, and direct multi-line contact hubs, the site provides a complete presentation of the brand's expertise.

*(Platformun temel amacı; konut alıcıları, yatırımcılar ve kentsel dönüşüm paydaşları için akıcı, ultra hızlı ve güven veren bir dijital deneyim sunmaktır. Çoklu fotoğraf destekli interaktif proje inceleme sistemi, scroll odaklı canlı sayaç animasyonları, gelişmiş lightbox galerisi ve doğrudan yetkili iletişim kanallarıyla markanın uzmanlığını eksiksiz şekilde aktarır.)*

## 🚀 Key Features (Temel Özellikler)

- 💎 **Prestigious & Modern Design System (Prestijli & Modern Tasarım Sistemi):** 
  Custom Navy & Gold corporate palette, glassmorphic frosted-glass accents, and refined typography (Montserrat & Open Sans) conveying trust, luxury, and solid architectural heritage. *(Güven, sağlamlık ve lüks hissini yansıtan Lacivert & Altın kurumsal renk paleti, modern cam (glassmorphism) efektleri ve Montserrat & Open Sans tipografisi.)*

- 🖼️ **Interactive Project Showcase & Multi-Photo Lightbox (İnteraktif Proje Vitrini & Gelişmiş Lightbox):** 
  Categorized architectural portfolio (Residential, Commercial, Urban Transformation) with dynamic multi-angle project galleries, interactive modal viewing, full-screen lightbox, thumbnail strip navigation, and touch/swipe & keyboard support. *(Konut, Ticari ve Kentsel Dönüşüm projeleri için çoklu fotoğraf desteğine sahip dinamik inceleme modalı, tam ekran lightbox, küçük resim gezintisi ve klavye/dokunmatik uyumlu galeri deneyimi.)*

- ⚡ **Zero-Dependency Static Architecture (Sıfır Bağımlılık & Yüksek Hız):** 
  Engineered purely with vanilla HTML5, modular CSS3, and modern ES6+ JavaScript. Ultra-low latency, zero external heavy framework overhead, instant page transitions, and 100/100 Lighthouse-oriented performance. *(Ağır framework yükleri olmadan, saf HTML5, modüler CSS3 ve modern ES6+ JavaScript ile inşa edilmiş sıfır bağımlılıklı, anında yüklenen ve maksimum hız sunan statik mimari.)*

- 📊 **Scroll-Triggered Live Metrics (Intersection Observer Sayaç Animasyonları):** 
  Dynamic counting animations (36+ Years of Experience, 25+ Completed Landmark Projects, 1000+ Happy Families) activated dynamically when scrolling into view via Intersection Observer API. *(Kullanıcı ekrana kaydırdığında tetiklenen 36+ yıllık tecrübe, 25+ tamamlanan prestijli proje ve 1000+ mutlu müşteri canlı sayaç animasyonları.)*

- 📸 **Optimized Next-Gen Media Engine (WebP Görsel Optimizasyonu):** 
  High-resolution architectural photography fully converted and compressed into modern `.webp` formats for instantaneous loading without sacrificing visual fidelity. *(Tüm mimari ve iç mekan fotoğraflarının görsel netlikten ödün vermeden ultra hızlı açılması için WebP formatında optimize edilmiş görsel varlıklar.)*

- 📍 **Integrated Contact & Location Hub (Kapsamlı İletişim & Lokasyon Entegrasyonu):** 
  Direct multi-executive contact routing (Contractors & Finance Directors), interactive Google Maps embed, click-to-call, email gateways, and structured address modules. *(Firma yetkililerine tek tıkla doğrudan arama ve e-posta bağlantıları, interaktif Google Haritalar entegrasyonu ve kurumsal merkez bilgileri.)*

- 📱 **Cross-Platform Fluid Responsiveness (Kusursuz Mobil & Tablet Uyumu):** 
  Mobile-first fluid responsive grid and flexbox structure, smart sliding mobile drawer navigation, adaptive header scroll states, and touch-friendly interface elements across all screen dimensions. *(Tüm ekran boyutlarında kusursuz çalışan esnek grid/flex yapısı, akıllı kayan mobil menü ve dokunmatik cihazlara özel optimize edilmiş etkileşimler.)*

- 🔍 **Enterprise SEO & OpenGraph Protocol (Kapsamlı SEO ve Sosyal Medya Uyumu):** 
  Optimized meta descriptions, keyword indexing, OpenGraph preview cards for social media sharing, dynamic sitemap.xml, robots.txt, and web app manifest integration. *(Arama motorlarında üst sıralar için optimize edilmiş meta etiketleri, OpenGraph paylaşım kartları, sitemap.xml, robots.txt ve webmanifest yapılandırması.)*

## 🛠️ Technology Stack (Kullanılan Teknolojiler)

### **Core Frontend & Architecture**
- **Markup & Structure:** Semantic HTML5 (W3C & Accessibility Compliant)
- **Styling & Design System:** Modern Vanilla CSS3 (Custom Variables / Design Tokens, Flexbox, CSS Grid, Glassmorphism, Keyframes)
- **Client Logic & Interactions:** Vanilla JavaScript (ES6+, Intersection Observer API, Custom Lightbox Controller, Touch/Keyboard Event Listeners)
- **Vector Icons:** [Lucide Icons](https://lucide.dev/) (Lightweight, crisp scalable vector iconography)
- **Typography:** Google Fonts (`Montserrat` & `Open Sans`)

### **Assets & Media Pipeline**
- **Image Optimization:** Next-Gen WebP Compression
- **Branding Assets:** High-resolution vector SVGs & Multi-size Favicons / App Icons

### **SEO, Performance & Deployment**
- **Hosting & Edge Delivery:** Cloudflare Pages / GitHub Pages (Static Global CDN)
- **Discovery & SEO:** Dynamic XML Sitemap, `robots.txt`, OpenGraph Protocol, Web Manifest (`site.webmanifest`)

## 📁 Project Architecture (Proje Dizin Yapısı)

```text
Bas Grup Web/
├── index.html                 # Main single-page web document (All sections)
├── kullanim-sartlari.html     # Terms of use & legal compliance page
├── css/
│   ├── variables.css          # Design tokens (Colors, Typography, Shadows, Spacing)
│   ├── base.css               # Reset, typography & global base rules
│   ├── layout.css             # Grid layouts, container structures, navbar & footer
│   ├── components.css         # Buttons, cards, badges, lightbox modal & UI items
│   ├── sections.css           # Section-specific styles (Hero, About, Projects, Gallery, Contact)
│   ├── animations.css         # Scroll reveal keyframes & transitions
│   └── responsive.css         # Breakpoint definitions for mobile, tablet & desktop
├── js/
│   ├── main.js                # Navbar scroll states, mobile drawer & core interactions
│   ├── animations.js          # Intersection Observer scroll trigger & dynamic counters
│   └── gallery.js             # Project multi-photo viewer & full-screen lightbox modal
├── assets/
│   ├── logo/                  # Vector SVG logos, transparent assets & favicons
│   └── images/                # Optimized WebP assets for Hero, About, Projects & Gallery
├── Evler/                     # High-resolution categorized project photos
├── site.webmanifest           # Progressive Web App manifest
├── robots.txt                 # Search engine crawler instructions
├── sitemap.xml                # SEO index map
└── README.md                  # Project documentation & presentation
```
